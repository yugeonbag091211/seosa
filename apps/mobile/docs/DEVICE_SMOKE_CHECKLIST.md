## 공통 원칙

- 상품 정체성은 `productId + mall + vendorItemId` 정확 조합이다. 어떤 화면에서든 **다른 옵션의 가격·그래프·알림**이 보이면 즉시 ❌ 이고 출시 차단이다.
- 판매처 링크는 `Linking.openURL` 로 OS 에 넘긴다. 앱 안 WebView 로 열리면 ❌ 이다.
- 실패 시 고치려고 테스트 기대값을 바꾸지 않는다. 원인을 기록한다.
