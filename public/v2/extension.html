④ 브라우저 확장 · PREVIEW

쿠팡 상품 페이지에서 바로 보는 가격 기록

상품 페이지 오른쪽 아래의 버튼을 누르면, SEOSA가 매일 쌓은 가격 기록과 같은 상품의 다른 판매처 가격을 작은 패널로 보여 드려요. 누르기 전에는 아무것도 보내지 않아요.

무엇을 보여 주나요

이 상품의 기록

쿠팡 상품 번호가 SEOSA 카탈로그에 있으면, 보고 계신 옵션의 가격 곡선과 최근 90일 중 지금 가격의 위치를 보여 드려요.

비슷한 상품의 기록

번호로는 없지만 제목으로 같은 상품을 찾았을 때예요. 보고 계신 상품의 기록이 아니라고 분명히 표시하고, 확신이 낮으면 «확신 낮음» 을 붙여요. 11번가·G마켓 페이지는 늘 이 방식이에요.

같은 상품, 다른 판매처

용량·색상·수량까지 같은 상품이라고 판정된 것만 보여 드려요. 닮았지만 확신할 수 없는 상품은 싸 보여도 넣지 않아요.

설치 (개발자 모드)

  1. SEOSA 저장소를 받아 extension 폴더를 준비해요.
  2. Chrome 주소창에 chrome://extensions 를 열어요.
  3. 오른쪽 위 개발자 모드를 켜요.
  4. 압축해제된 확장 프로그램 로드를 누르고 extension 폴더를 골라요.
  5. 쿠팡 상품 페이지를 열면 오른쪽 아래에 SEOSA 가격 기록 보기 버튼이 생겨요.

패널의 «이 버튼 숨기기» 로 숨길 수 있고, 브라우저 툴바의 확장 아이콘을 누르면 다시 보여요.

쿠팡 · 11번가 · G마켓 상품 상세 페이지그 페이지에만 버튼을 그려요. 검색·장바구니·주문 페이지에서는 실행되지 않아요.

요청하지 않는 권한: tabs · activeTab · scripting · cookies · history · webRequest · 모든 사이트 접근.

개인정보

  • 언제 — 버튼을 눌렀을 때만 보내요. 같은 상품을 다시 열면 다시 보내지 않아요.
  • 무엇을 — 쿠팡: 상품 번호 · 옵션 번호 · 아이템 번호(주소에 있을 때) · 상품명. 11번가·G마켓: 상품명만.
  • 어디로 — https://seosa.ai.kr/api/lookup 한 곳. 쿠키와 리퍼러 없이 보내서 누가 눌렀는지 알 수 없어요.
  • 저장 — 버튼 보이기 설정 하나(chrome.storage.local). 서버는 이 요청으로 아무것도 저장하지 않아요.
  • 읽지 않는 것 — 쿠키, 로그인 정보, 입력란, 장바구니, 방문 기록, 다른 탭.

미리 해 보기

확장이 서버에 묻는 것과 같은 질문을 이 페이지에서 해 볼 수 있어요. 주소는 이 페이지 안에서만 해석하고, 서버로는 번호와 상품명만 보내요.

가격은 SEOSA가 확인한 시점의 기록이에요. 실제 결제 금액은 판매처에서 확인해 주세요.
