## 검증 방법

1. 비공개 Vercel Preview에서 실제 GPT 모델과 Neon의 읽기 전용 상품 DB를 사용.
2. 고유 질문 10개 실행, 이후 서로 다른 고유 질문 100개 실행.
3. 예산 상한·하한, 상품 종류, 제품 모델·용량·세대, 제외 조건, 중고, 가격, 대화 상태, 비교 양쪽 후보를 자동 평가.
4. 자동 PASS에서도 잘못된 상품형태·부품 혼입 등을 재검토하여 일부 FAIL로 조정.
5. 자동 UNVERIFIED 중 같은 DB의 다른 질문에서 실제 적합한 후보가 반환된 8건을 검색 누락 FAIL로 조정.
6. 상품이 없다는 응답을 무조건 정상으로 판정하지 않고, 반대 증거가 없는 16건만 미검증 유지.

## 주요 개선 과제

- P0 카테고리 정규화: 완제품/저장장치/외장 SSD/무선 이어폰 등을 사용자 의도에 맞게 정규화하고 제목 검증 별도 유지.
- P0 상품 형태 구별: 자전거 헤드셋 스템, 이어클립 이어폰, 액세서리·부품, 옵션이 혼재된 SSD의 가격 불명확 문제 제거.
- P0 검색 누락 방지: 동의어/사양 표현 차이에도 같은 DB에 존재하는 제품을 찾도록 검색 후보·분류·제약조건을 분리.
- P1 비교: 청소기와 공기청정기처럼 다른 카테고리 비교도 두 대상을 각각 검색하고 둘 다 검증.
- P1 미검증 16건: 읽기 전용 SQL로 원본 재고·상품 제목을 직접 확인해 재판정.
- Production 전환 금지: 수정 후 동일 100문항과 별도 홀드아웃 질문을 재검증해야 함.
