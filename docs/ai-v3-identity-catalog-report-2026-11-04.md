- `api/_ai-v3-core.js`: 부정확한 모델을 거절하고 `titleEvidence` 및 `specEvidenceSource=seller_listing_title_only`를 카드에 표시. 구매처 제목에 없는 성능·사양을 만들어 설명하지 않음.
- `api/_ai-v3-catalog.js`: DB 정확 일치 검색 실패 시 단어별 조회, 제목·키워드 기반 재조회, 복수 검색조건의 제한된 읽기 전용 조회. Preview의 전역 판매처 API 호출 안전장치 해제 금지.
- 일반 채팅 UI/수집기/기존 Production AI는 미변경.

이전 첫 Preview에서 `아이패드 추천해줘`는 카드 4개를 반환함. 일반 추천에 비해 정확한 옵션 요청의 검색 후보 확보가 어려움.

**중요:** 이 결과의 '일치'는 판매자가 기재한 상품명에서 확인된 문자열에 대한 일치만 의미함. 제조사 공식 사양, 실제 재고, 실시간 결제 가격 또는 배송비가 검증된 것은 아님. 아이패드 에어 M4 256GB 두 카드의 표시 가격은 1,988,240원 / 1,848,000원(해당 테스트 시점의 저장 데이터)이었으며 모두 배송비와 현재 가격 확정 여부는 미확인.

### Preview 오류 처리
첫 `2de37a6` 배포에서 아이패드 에어 M4 256GB 질문에 오류 발생: 긴 구절의 DB 검색 실패 후 판매처 검색을 호출하려 했으나 `SEOSA_DB_READONLY=1`이 전역 quota-acquire RPC를 차단함. RPC 허용 예외를 추가하거나 DB 쓰기 차단을 해제하지 않고, 읽기 전용 DB 검색 범위를 확장하여 `c0e2433`에서 HTTP 200 복구, `dc59072`에서 일치 카드 2개 확보.

## 남은 핵심 문제
1. 판매 제목이 영문·약칭이거나 저장용량·세대 정보가 누락되면 일치 상품도 `identity_unverified`로 제외될 수 있음.
2. 목록 검색에서 정확한 모델이 DB에 없거나 인덱스가 부실하면 카드 0개가 정상 응답으로 나옴. 상품 수집 범위와 제목 정규화·정규화된 SKU/옵션 테이블 점검 필요.
3. 상품 사양은 판매 제목만을 근거로 비교하며 공식 제조사 데이터와 교차 검증하지 않음.
4. 본 테스트는 소수의 기능 확인 사례로, 예전 운영 AI와 대등한 조건의 온라인 A/B 정확도 평가는 아직 없음.
5. 더 큰 온라인 평가 전 비용 상한·분산 rate limiting·성능 계측을 구현해야 함.
