## 미완료 / 출시 차단
1. R2 버킷 seosa-price-history 최소권한 Access Key ID 및 Secret Access Key가 연결되지 않음. 사용자 전용 데스크톱 실행파일 SEOSA-R2-Connect.cmd 생성, 비밀값은 Windows 현지 프롬프트에서만 받고 DPAPI 암호화해 앱 데이터 폴더에 저장. 채팅에 키 공유 금지.
2. 전체 기존 API(.from/.rpc 수십 곳) 완전 기능동등성/에러 시맨틱 검증 미완료. 모듈별 로깅, 인증, 수집 배치, 상품 옵션, 결제, AI 등 별도 테스트 필요. API fallback도 어떤 상품이나 가격을 지어내면 안 됨.
3. R2 가격 이력은 단건 히스토리와 상품 페이지의 옵트인 읽기 구현·검증까지 완료. 가격 배치, AI 가격통계, 신뢰/가격 하락/모든 그래프 경로는 아직 DB만 읽음. **DB에서 price_history를 삭제하면 안 됨.**
4. Neon 기본 production 브랜치 빈 상태. Vercel Production 환경변수 미변경, 사이트는 여전히 Supabase Free Egress 제한에 영향을 받음.
5. 전체 npm test 실행 결과 exit 1. scripts/test-identity-review-mutations.js 에서 'mutation survived: hard-conflict server gate'. 이번 이전에서 해당 보안 코드를 수정하지 않았으나, 테스트가 현재 main 코드에서도 재현되는지는 별도 검증이 필요. 이 상태로 Production release 금지.
6. 무료 운영 비용 모니터링 필요: Neon DB 저장 용량과 네트워크 사용량, R2 읽기 요청량/전송량, Vercel 함수 제한, 외부 공급자 API 쿼터. 100% 무제한 무료 보장 불가.

## 후속 절차
1. 사용자 Cloudflare Dashboard R2 → Manage R2 API Tokens에서 **seosa-price-history 한 개 버킷에만 Object Read & Write 권한** 토큰 발급; 노트북 바탕화면 SEOSA-R2-Connect.cmd 실행, 로컬에만 키 입력, UPLOAD를 직접 확인. 원본 및 백업 삭제 안 함.
2. R2 HEAD 검증 256 shard와 manifest 완료 확인. 로컬이 아닌 실제 R2 GET로 43개 원본 기록 재검증.
3. 모든 통계·가격 이력 경로에 새 히스토리 소스 어댑터 통합하고 회귀 테스트. 구데이터 정리 시점은 별도 데이터 무결성 검증 후에만.
4. 기존 API, 수집, 회원, 결제, AI, 모바일, SEO 등 Preview E2E 회귀 테스트 통과. 실패한 mutation 보안 테스트 원인 파악.
5. 최종 증분 백업 및 운영용 Neon DB 준비, Vercel Preview 점검, 네트워크/비용 검증 후 명시적 사용자 승인 시 운영 전환.
6. Supabase는 **사용자 명시적 삭제 승인과 2차 백업 검증 전까지 절대 삭제하지 않음.**
