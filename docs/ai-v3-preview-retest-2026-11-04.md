## 확인된 개선
1. 배송비를 알 수 없는 경우 가격을 0원으로 꾸미지 않고, `budgetStatus=listing_only_shipping_unverified`, `shippingFee=null`, `totalPrice=null`을 반환해 임시 후보임을 명시.
2. 명시적 무료배송 정보가 있는 상품만 배송비 0으로 인정. 상품가 자체가 예산 초과이면 임시 후보에서도 배제.
3. 사용자가 중고를 원하지 않는 경우 중고·리퍼 제목을 기본 제외. 부속품 제목도 필터링.
4. 비교는 각각 최대 40개 후보를 검사하고 각 측에 균형 있게 후보를 배정. 최종 카드 2개와 설명의 상품이 일치.
5. 후속 질문의 예산과 제외 조건, 비교 대상 보존 개선.
6. 실제 GPT 호출·입력 및 출력 토큰 계측 추가. 유료 사용의 정확한 청구액은 확인하지 않았음.

## 주의 / 미완료
- **실제 추천 정확도 성공률을 측정한 것은 아님.** 온라인 요청 5건은 작은 기능 검증 표본이고, 독립 평가자가 가격·모델·상품 적합성을 확인하지 않았다.
- 기존 운영 AI와 동등 환경의 A/B 비교가 아직 없음. 기존 AI를 같은 읽기 전용 Preview에서 호출했을 때 DB RPC 차단으로 검색에 실패했으며 공정한 정확도 비교로 사용할 수 없다.
- 현재 비교 설명은 실제 상품 2개의 **표시 가격 및 확인된 배송비**에 대한 비교일 뿐, 벤치마크나 상세 사양 비교는 아님.
- 카탈로그 DB의 갱신 시각 및 품질을 별도로 보증하지 않음. 배송비 미확인 카드가 많으므로 UI에는 임시 후보 경고를 반드시 노출해야 함.
- 사용자의 장기 대화 상태는 별도 영구 저장을 구현하지 않았음. 새로운 AI는 일반 사용자 UI와 아직 연결되지 않음.
- 검색·리랭킹을 위한 카테고리와 부속품 분류는 초기 규칙이므로 실제 다양하고 새로운 카테고리에서 검증이 더 필요함.
- 유료 모델 호출량 상한/공통 분산 rate limit, 세부 비용 계측, 실제 판매처 신뢰도 및 사양 정규화가 공개 출시 전 필요.
