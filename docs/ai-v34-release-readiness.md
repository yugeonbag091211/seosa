## 출시 차단 요인 (해결 순서)

1. **실제 온라인 측정 없음** — 격리 Preview(전용 Neon 브랜치 + 쿼터 저장소, `SEOSA_DB_READONLY` 의미 유지)를 띄우고 `tools/ai-eval/promptfooconfig.preview.yaml`로 실 GPT E2E를 돌려야 한다(비용 상한 ≤ $10 강제, 예상 비용: v3.3 실측 토큰 기준 100문항×3턴 이하 ≈ $0.1 미만). 이 PC에는 OpenAI 키가 없고, 브랜치 푸시(=Preview 생성)는 이번 작업 범위 밖이라 실행하지 않았다.
2. **Live-first / 판매처 채널 미검증** — 격리 쿼터 저장소 없이는 공유 운영 쿼터를 쓰게 되므로 금지. 시간 초과·429·빈 결과·stale-cache는 모의로만 검증.
3. **남은 엔진 결함 5건**: V023 브랜드 키워드 스터핑, V030 혼합 프로모션 페이지, V100 오래된 기록이 최신순 40행 밖이면 "부재"로 안내, H028 "그램 16"(인치 표기 없음) 화면 크기 미파싱으로 실재 상품 13건 미발견, H022 후속 턴 "S10 FE로"에 FE+ 혼입.
4. **가격 신선도 = DB 기준 10일** — 카드에 수집 시각을 표시하고 10일 초과는 숨기지만, 실시간 재고·가격 확인은 아니다. 스냅샷 기준 카탈로그의 63%가 10일 초과라 DB-only 모드에서는 "가격이 오래돼 추천하지 않음" 응답이 늘어난다(정직하지만 사용성 저하) → 수집 주기 또는 판매처 실시간 재확인과 함께 가야 한다.
5. **pgvector 운영 반영 비용** — 77,737×256차원 = 테이블+HNSW ≈210MB. Neon Free 한도 1GB 중 운영 브랜치가 이미 ~700MB → `halfvec`/128차원/신선 상품만 임베딩 + 비용 재측정 없이는 불가. 또 해시 임베딩은 holdout 이득이 없었으므로 의미 임베딩(OpenAI `text-embedding-3-small`, 77,737×~25토큰 ≈ $0.04 추정, 미실행) 평가가 먼저다.
6. **CI 게이트 연결** — `.github/workflows/ai-v34-eval.yml`은 PR에서만 돈다. 실패 시 배포를 막으려면 저장소 설정에서 이 잡을 main의 필수 상태 검사로 지정해야 한다(설정 변경은 사용자 결정, 이번에 하지 않음). 워크플로 자체는 GitHub에서 아직 한 번도 실행되지 않았다(로컬 브랜치).
7. **평가기 개선 필요** — v2 평가기는 가격 신선도·되묻기·장애 기준이 없고 "N만원대"를 잘못 해석한다. v3.4 판정기는 사양어 금지('NVMe'·'백라이트 키보드')와 표기 변형('JBLCHARGE5', '제이비엘', 'Wi-Fi', 'T7실드')에 약했다. 봉인 세트는 결과를 보고 고치지 않았으므로, **다음 봉인 세트**에서 판정 조건을 보강해야 한다.
