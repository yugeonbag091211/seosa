## C. 측정하지 못한 실패 원인 (NOT_MEASURED)

- ⑤ 판매처 API 오류의 실제 빈도·형태: 쿠팡·ADPICK 실호출 0회(공유 운영 쿼터·격리 쿼터 저장소 없음). 시간 초과·한도·빈 결과·stale-cache는 fast-check 속성 14와 하이브리드 통합 테스트에서 **모의**로만 검증.
- ① GPT 계획 오류: 오프라인 실행은 스크립트 플래너라 GPT-4.1-mini의 실제 계획 품질은 측정하지 않았다(OpenAI 키가 이 PC에 없음, Preview E2E 미실행).
- ④ 의미 기반 벡터 검색: 해시 임베더는 어휘 모델이라 "의미가 같고 단어가 다른" 질의(예: '자취방 청소' → 로봇청소기)의 재현율은 측정하지 않았다.

## D. 평가기 오류 (판정기 불일치 수동 검토, `reports/ai-v34-evaluation/review-v34-final.json`)

개발 세트 최종 NEEDS_REVIEW 24건: v3.4 판정기 오류 8(노트북 사양의 'NVMe'·'백라이트 키보드'를 금지어로, "JBLCHARGE5"·"제이비엘", "Wi-Fi" 하이픈, "T7실드" 표기), v2 판정기 오류 8(“30만원대”를 300,000–309,999로 해석, 되묻기·장애·오래된 가격 판정 기준 없음), 확인 불가 4(2014년형 갤럭시탭4 79,000원 등 상태 불명), 하한 경계 2(9,800 vs 1만, 49,770 vs 5만), 남은 엔진 결함 3. **봉인 정답 조건은 결과를 보고 고치지 않았고**, 헤드라인 PASS_ONLY(55%)에도 반영하지 않았다.

평가기 쪽에서 배운 것(다음 봉인 세트에 반영할 규칙): 금지어는 사양 문맥(“NVMe 512G”, “백라이트 키보드”)과 구별해야 하고, 짧은 영문 브랜드는 붙여 쓴 표기(“JBLCHARGE5”)와 한글 표기(“제이비엘”)를 함께, "Wi-Fi"처럼 하이픈이 든 표기를 정규화해야 한다. 기존 v2 평가기는 가격 신선도를 전혀 보지 않아 v3.3의 오래된 가격 카드를 PASS로 셌다(v3.3 기준 v2 단독 66% vs 합의 33%).
