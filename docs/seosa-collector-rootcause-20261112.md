3. 13:19 KST 완료된 한 실행의 당일 누적 제품 outcome 집계:

## 원인 분리 (원인 하나로 단정하지 말 것)
- **우선 병목**: 검색어 기반 판매처 검색의 제한된 상위 결과에 기존 상품 ID가 없어서 재발견 실패 (no_match).
- **별도 병목**: 쿠팡 정확한 vendor 옵션 mismatch (785), ADPICK 시간 종료 (2,731), 순환 수집 범위 및 저장된 상품의 장기 stale 축적.
- **별도 출시 차단**: v3.4는 로컬 코드/오프라인 평가에만 존재. 실제 GPT·판매처·DB를 동시에 통과한 E2E 성공률 없음.
- **별도 지표 오류 의심**: 수집 로그 일부 요약에서 출력식 '7325 + 10276 = 18386'은 산술적으로 맞지 않는다. 분류별 outcome은 합계가 맞지만, 요약식·인바리언트 구현을 독립 검토해야 한다.
