## 남은 F11의 근본 원인

- JBL의 공식 한국 상품 페이지 [TUNE 770NC](https://kr.jbl.com/TUNE770NC.html)는 이 모델을 **무선 오버이어 헤드폰**으로 명시한다. 모델 유형 자체는 확인되었다.
- Neon DB에서 해당 모델을 8만원 이하로 검색하면 **1건(50,100원, ADPICK, 수집일 2026-09-17)**이 발견되지만 제목에 `이어폰`과 `헤드폰`이 혼재한다.
- 서버의 `productTypeMatches`는 헤드폰 요청에서 판매 제목에 '이어폰'이 있으면 거부한다. 이는 실제 재현한 검색 누락의 직접 원인이다.
- 그러나 해당 판매 기록이 **오래되어 현재 50,100원에 헤드폰 본체가 판매되는지 확인되지 않았다**. 카테고리 필터를 무작정 완화해 이 가격을 실시간 현재가로 노출하는 것은 부적절하다.
- 코드 보완: 공식 JBL 모델 TUNE 770NC의 제품 정체는 예외적으로 확인하되 **실시간 제휴 API `api` 또는 유효한 `cache` 출처가 있는 경우에만** 이 분류를 허용한다. 오래된 DB (`_source=db`) 50,100원 상품은 그대로 차단한다. `api/_ai-v33-official-models.js`와 `scripts/test-ai-v33-f11-live-only-20261110.js`의 전용 테스트 **6/6 PASS**.
- 향후 **실제 제휴사 조회로 현재 판매가·완제품 여부가 확인된 상품만** 정답으로 인정하고 테스트한다. 모의 실시간 목록으로 재현한 성공은 실제 판매처 검증으로 계산하지 않는다.
