# ① 구매 타이밍 — 설계 노트

| 질문 | 답하는 곳 |
|---|---|
| 지금 가격은 기록에서 어디쯤인가 | `_pricestat.fairness` (기존) — 90일 분포 백분위 |
| 기다리면 더 내려갈 확률 | `_timing` empirical analog — 지금과 비슷한 가격 위치(백분위 ±20)였던 과거 날들의 «그 뒤 H일 최저가 / 그날 가격» |
| 그 확률을 믿어도 되는가 | `_timing` walk-forward 백테스트 — 이 상품의 실제 `price_history` |

## 방법 단계

1. **empirical-analog** — 완전히 지나간 H일 창을 가진 과거 날 ≥ 12개(비슷한 위치) 또는 ≥ 8개(전체).
2. **volatility-band** — 표본이 모자라면 일간 로그수익률 σ 로 무작위 보행 최저가 분포만 낸다 (반사 원리). 방향 정보가 없으므로 **행동을 권하지 않는다**.
3. **insufficient** — 관측 < 10일, 기간 < 14일, 마지막 관측 > 7일 전.

## 권고 규칙

- `WAIT` : P(5% 이상 하락) ≥ 0.5 **그리고** 예상 최저가 중앙값 ≤ 현재가 × 0.97
- `BUY_NOW` : 가격 위치 ≤ 하위 30% **그리고** P(5% 이상 하락) < 0.25
- 그 밖 `NEUTRAL`. 고정가(폭 < 5%)는 `NEUTRAL` — 언제 사도 비슷하다.
- 보정: `_deal` 판정이 WAIT/DONT_BUY 면 `BUY_NOW` 금지. 백테스트가 `weak` 면 WAIT/BUY_NOW 를 `NEUTRAL` 로 내린다.

## 백테스트

- 시점 t 의 예측은 `d_s + H ≤ d_t` 인 표본만 쓴다 → **미래 누설 없음**. 테스트가 «시점 t 의 백테스트 예측 = t 까지 자른 기록으로 새로 계산한 예측» 을 고정한다.
- 지표: 브라이어(5% 하락 확률) vs 기본값(평소 하락 빈도), skill, 예측 구간 적중률, 권고 적중률,
  «기다려라» 절약(예측 중앙값을 목표가로 걸고, 안 닿으면 창 끝 가격에 샀다고 가정 — 음수 가능).
- 판정: 표본 < 20 → `insufficient`. skill ≥ 0.05, 또는 브라이어 ≤ 0.10 이면서 skill ≥ −0.05 → 확률 OK. 권고 5회 이상이면 적중률 ≥ 55% 도 필요 → `reliable`, 아니면 `weak`.

## 한계 (정직하게)

- 한 상품의 과거만 본다 — 같은 카테고리의 다른 상품에서 배우지 않는다. 기록이 짧은 상품은 대부분 `insufficient`·`volatility-band` 다.
- 겹치는 창을 쓰므로 백테스트 표본은 서로 독립이 아니다. 표본 수는 실제 정보량보다 크게 보인다.
- 카탈로그 전체 정확도는 `scripts/backtest-timing.js` (운영 DB 읽기 전용)로 잰다. **이 저장소에서는 자격증명이 없어 아직 돌리지 않았다.**
