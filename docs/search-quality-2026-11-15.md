# SEOSA 검색 정확도 1차 수정 — 2026-11-15

**상태: 코드 수정 + 오프라인 테스트 통과, 운영 미배포.** 작업 브랜치: `fix/search-quality-20261115`. 메인 브랜치·Neon DB·Vercel 설정·수집기 실행 상태는 변경하지 않음.

## 증거와 근본 원인

- 2026-11-15 실제 운영 `/api/search?keyword=아이패드%2010세대` 응답 22건 중 아이패드 본품과 '매직키보드 폴리오'가 **관련도 1.00** 동점; 보호필름·케이스·도서도 반환.
- `api/search.js`는 `rankItems(..., {minScore:0})`로 검색 품질 하한선을 꺼놓음. 이후 최저가 정렬은 잘못 남은 부속품을 앞세울 수 있음.
- 기존 `_shop.relevantItems`의 1차 검색 필터는 검색어 토큰 **하나만** 제목에 있어도 통과시킴.
- 기존 코드는 품질 검증 **이전**에 `saveProducts`를 호출하므로 검색어로 잘못 분류된 상품이 가격 DB에 저장될 수 있음.
- 운영 Neon 읽기 전용 분석: `products` 78,670행, 10일 넘은 행 53,631개(68.2%). `keyword='수영복'` 47개 중 27개는 제목에 수영복이 없었고 로션·콜라·생연어 등이 있었음. `price_history.source='collect'`로 오염된 키워드의 가격 갱신 지속 확인.
- 개선 v3 모니터 테이블과 프로필 테이블 운영 DB 부재 → v3 라우트가 legacy로 폴백. 별도 마이그레이션 작업 필요.
- 쿠팡 한 요청 최대 10건, 애드픽 최대 20건. 캐시 6시간, stale fallback 24시간. 이 제한은 이번 수정에서 변경하지 않음.

## 이번 수정

1. 일반 검색의 기본 관련도 기준선을 복원하고, **최종** 관련도 점수에도 `MIN_SCORE` 기준 적용.
2. 사용자가 기기 본품을 검색할 때 기존 AI의 `principalItem / productTypeMatches / listingGuard`를 재사용해 다른 종류의 기기, 키보드·케이스·필름, 출판물을 제거. 액세서리 명시 검색은 제한하지 않음.
3. 본품에 충전기·케이스가 **포함/증정**된 정상 구성품을 오판하지 않도록 별도 보완.
4. 상품 필터링 **이후** 검증된 상품만 `saveProducts`에 전달. 검색 경로로 새 오염 데이터를 저장하는 위험 감소. 기존 DB의 과거 오염 데이터는 삭제하지 않음.
5. `사용설명서` 등 매뉴얼 상품을 AI 공통 출판물 가드에 추가하되, 본품에 매뉴얼이 동봉된 경우는 보존.

## 오픈소스 통합 — 다음 별도 단계

- repo에 이미 `api/_ai-v34-vector.js`, `api/_ai-v34-embedding.js`, `api/_ai-v34-fusion.js`의 `pgvector`·하이브리드 검색 코드가 있음. 현재 운영 Neon에는 `vector` 확장 및 `ai_v34.product_embeddings` 테이블이 없으므로 **아직 사용 불가**.
- PostgreSQL `pgvector`가 우선. 한국어 복합 검색이 실제로 미흡하면 Kiwi 또는 검증된 다국어 임베딩/리랭킹 추가 검토. BGE 계열 리랭킹은 GPU·호스팅 비용이 생길 수 있어 즉시 활성화하지 않음.
- 먼저 변경 없는 DB 스냅샷으로 200개 이상 비개발 홀드아웃 질문 테스트. 본품/부속품 정확도, Recall@K, 미검증률, p95, 비용을 기존 DB-first와 비교. 의미 검색이 키워드 검색보다 낮으면 롤아웃 보류.
- 안전한 실행 순서: **검색 PR 리뷰/반영 → 오염 데이터 격리 계획 → V3 모니터 스키마 검증 → 분리된 pgvector 시험 DB → holdout 측정 → 10%/50%/100% 운영 단계 배포**. 필요 권한/사용자 승인 전에는 운영 DB·API 한도·유료 서비스를 변경하지 않음.
