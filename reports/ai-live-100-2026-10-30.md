**해석 주의:** 이 8건 중 2건은 실제 GPT가 실행되지 않은 것이지, GPT가 거짓 답변을 한 사례가 아님. 5건은 비정상/공격성 입력에서의 검색 의도 실패이며, 1건은 모델 1위 식별 또는 평가기 정답 오류 가능성이다. 92%를 실사용 정답률로 표기하지 않는다.

### 실패 유형별 우선 작업

1. **입력/의도 계약:** Unicode NFKC·공백·제어 문자 정규화, 공격성 텍스트 격리, '상품명'과 지시문 분리. 사용자의 본래 모델·예산·제외 조건을 잃지 않도록 독립 회귀 추가. 정상 명령 인식·보안 완화를 위한 무조건 패치 금지.
2. **평가기 정답 일관성:** 모델/크기/옵션/예산의 골드 라벨이 실제 질의와 모순되는지 자동 검증. `R2-208` 재검토 전 불합격을 곧바로 모델 오류로 확정하지 않음.
3. **GPT 미호출 케이스:** '상품 부재에 대한 안전한 결정론 답변'을 실제 GPT 성공·실패와 분리해 `NOT_APPLICABLE` 또는 `UNVERIFIED_LLM`로 집계.
4. 실제 GPT + 실제 상품 API + 읽기 전용 원장에 대한 *확대* 실측은 아직 필요하며, 100문항 고정 카탈로그 테스트를 대신 사용하면 안 됨.
